# 서학동성당 홈페이지 — 구조와 설정 안내

관리자 페이지: 주소 뒤에 `/admin/`

## 구조 한눈에 보기 (모두 무료, 결제수단 등록 없음)

| 무엇을 | 어디에 |
|---|---|
| 사이트 실행 | **Cloudflare Workers** (`src/worker.js` + 화면 파일 `public/`) |
| 공지·주보·갤러리·접속 팝업·알림함·알림 구독자·관리자 명단·오늘의 말씀 | **Cloudflare D1** 데이터베이스 `seohakdong-church` (표 구조: `migrations/`) |
| 사진 파일 | 이 GitHub 저장소 `public/assets/img/uploads/` (사진 정보는 D1에) |
| 관리자 로그인 | 구글 로그인 (Firebase Authentication, 무료) |
| 휴대폰 알림 | Firebase Cloud Messaging (무료) |
| 오늘의 말씀 자동 갱신 | 매일 00:00 GitHub Actions가 서버를 호출 → 서버가 가톨릭굿뉴스에서 읽어 D1에 저장 (실패하면 GitHub가 메일로 알려줌) |

- 글은 저장하면 **바로** 홈페이지에 반영됩니다.
- 사진은 저장소에 커밋되고 1~2분 뒤 정식으로 배포되지만, 그 사이에도 서버가 GitHub에서 직접 읽어 **바로** 보여줍니다.
- D1 무료 한도(하루 읽기 500만·쓰기 10만, 5GB)를 넘어도 요금이 나가지 않고 오류만 납니다.
- 사진은 올릴 때 자동으로 줄여서(긴 변 1600px) 1년 1,000장 기준 약 300MB씩 늘어납니다.
  저장소가 1GB쯤 되면 오래된 연도 사진을 보관용 저장소로 옮기는 정리를 합니다.

## 한 번만 해두는 설정

### A. 서버 비밀값 (Cloudflare 대시보드 → Workers & Pages → `seohakdong-catholic-church` → Settings → Variables and Secrets)

| 이름 | 무엇 | 상태 |
|---|---|---|
| `FIREBASE_SERVICE_ACCOUNT` | Firebase 서비스 계정 키 JSON (알림 발송용) | 설정됨 |
| `CRON_SECRET` | 오늘의 말씀 자동 갱신 암호 (GitHub Actions 비밀값 `CRON_SECRET`과 같은 값) | 설정됨 |
| `GITHUB_TOKEN` | 관리자 페이지에서 사진을 저장소에 저장할 GitHub 토큰 (이 저장소 Contents 읽기/쓰기만) | 설정됨 (2026-09-26) |

**GITHUB_TOKEN 다시 만들 때 (만료되었거나 바꿀 때)**
1. github.com → 오른쪽 위 프로필 → **Settings** → 맨 아래 **Developer settings**
2. **Personal access tokens → Fine-grained tokens → Generate new token**
3. Token name: `seohakdong-worker`, Expiration: **No expiration**(또는 가장 긴 기간)
4. Repository access: **Only select repositories** → `SEOHAKDONG-CATHOLIC-CHURCH`
5. Permissions → **＋ Add permissions** → **Contents** 선택 → **Read and write** (Metadata 읽기는 자동으로 같이 붙음)
6. **Generate token** → 나오는 `github_pat_...` 복사
7. 위 Cloudflare 화면에서 **Add** → Key `GITHUB_TOKEN`, Value 붙여넣기, **Secret 체크** → **Add variable and deploy**

### B. 자동 배포 연결 (코드·사진이 저장소에 올라가면 자동으로 사이트에 반영) — 연결됨 (2026-09-26)

Cloudflare 대시보드 → Workers & Pages → `seohakdong-catholic-church` → **Settings → Build → Connect**
→ GitHub 저장소 `SEOHAKDONG-CATHOLIC-CHURCH`, 브랜치 `main` 선택
→ Build command는 비워두고, Deploy command는 기본값(`npx wrangler deploy`) 그대로 → 저장

### C. 카카오맵 도메인 등록

https://developers.kakao.com → 내 애플리케이션 → 서학동성당 앱 → **플랫폼 → Web → 사이트 도메인**에
`https://seohakdong-catholic-church.jangsangyun0310.workers.dev` 추가
(추가하기 전에는 "오시는 길" 지도 대신 "카카오맵에서 열기" 버튼이 보입니다)

### D. Firebase (이미 설정됨)
- Authentication → 승인된 도메인에 새 주소 추가 완료
- Firestore는 더 이상 쓰지 않습니다 (예전 데이터는 모두 D1으로 옮김)

## 개발·배포 명령 (C:\project2 에서)

| 명령 | 하는 일 |
|---|---|
| `npm test` | 서버 테스트 (로컬 D1 + 가짜 구글/GitHub) |
| `npm run test:browser` | 실제 브라우저로 홈페이지·관리자 화면 테스트 (결과 화면은 `test-results/`) |
| `npm run dev` | 내 컴퓨터에서 사이트 띄워보기 |
| `npm run deploy` | D1 표 구조 변경 적용 + 사이트 배포 |

표 구조를 바꿀 때는 `migrations/0002_....sql` 처럼 새 파일을 추가하고 `npm run db:migrate:remote` 로 적용합니다.

## 외국어 보기 (따로 설정할 것 없음)

홈페이지 오른쪽 위 🌐 버튼으로 English / 日本語 / 中文을 고를 수 있습니다.
관광객이 주로 보는 **미사시간·본당 소개·오시는 길**만 번역되어 있고,
공지·주보·갤러리처럼 관리자가 올리는 내용은 한국어 그대로 보입니다.

외국인에게 바로 해당 언어로 열리는 주소: 주소 뒤에 `?lang=en` (일본어 `?lang=ja`, 중국어 `?lang=zh`)

※ 미사시간·주소·전화번호를 바꾸면 `public/assets/js/i18n.js`의 외국어 문장도 같이 고쳐야 합니다.

## 평소 쓰는 법 (관리자분들께 알려드릴 내용)

- 홈페이지 맨 아래 작은 글자 **"관리자"** 를 누르고 구글 계정으로 로그인
- 한 번 로그인하면 그 다음부터는 홈페이지 오른쪽 아래에 **"✏️ 관리"** 버튼이 바로 보입니다 (관리자에게만 보임)
- 저장하면 **바로** 홈페이지에 반영됩니다
- 다른 관리자는 대표 관리자가 **관리자 명단**에서 지메일 주소를 추가하면 같은 방법으로 쓸 수 있습니다
- 카카오톡 안에서 열면 구글 로그인이 안 될 수 있으니, 크롬/삼성인터넷/사파리로 여세요
