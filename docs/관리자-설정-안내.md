# 서학동성당 홈페이지 — Cloudflare 이전 및 관리자 기능 설정 안내

홈페이지는 이제 **Netlify 대신 Cloudflare Pages**에서 돌아가고,
관리자는 **구글(지메일) 계정으로 로그인**해서 공지·주보·갤러리·팝업·알림을 관리합니다.
사진과 글은 GitHub 저장소에 저장되므로 Firebase Storage(카드 등록)는 필요 없습니다.

아래 설정은 **한 번만** 하면 됩니다. 순서대로 따라 하세요.

---

## A. GitHub 토큰 만들기 (관리자 페이지가 저장소에 글/사진을 저장할 때 씀)

1. github.com 에 `jangsangyun0310-sketch` 계정으로 로그인
2. 오른쪽 위 프로필 사진 → **Settings** → 왼쪽 맨 아래 **Developer settings**
3. **Personal access tokens → Tokens (classic)** → **Generate new token (classic)**
4. 아래처럼 채우기
   - Note: `seohakdong admin`
   - Expiration: **No expiration**
   - 체크: **repo** (맨 위 항목 하나만)
5. 맨 아래 **Generate token** → 나오는 `ghp_...` 글자를 복사해 둡니다 (이 화면을 벗어나면 다시 못 봅니다)

## B. Cloudflare Pages 만들기

1. https://dash.cloudflare.com 가입/로그인
2. 왼쪽 **Workers & Pages** → **Create** → **Pages** 탭 → **Connect to Git**
3. GitHub 연결 허용 → 저장소 **SEOHAKDONG-CATHOLIC-CHURCH** 선택 → **Begin setup**
4. 아래처럼 채우기
   - Project name: `seohakdong-church` (홈페이지 주소가 `https://seohakdong-church.pages.dev` 가 됩니다)
   - Production branch: `main`
   - Framework preset: **None**
   - Build command: **비워두기**
   - Build output directory: **비워두기** (또는 `/`)
5. **Save and Deploy** → 1~2분 뒤 배포 완료
6. 프로젝트 → **Settings** → **Variables and Secrets** → **Add** 로 두 개 추가 (둘 다 Type: **Secret**)
   | 이름 | 값 |
   |---|---|
   | `GITHUB_TOKEN` | A에서 복사한 `ghp_...` |
   | `FIREBASE_SERVICE_ACCOUNT` | 컴퓨터의 `C:\project2\scripts\serviceAccountKey.json` 파일을 메모장으로 열어 **내용 전체** 복사해 붙여넣기 |
7. **Deployments** 탭 → 맨 위 배포의 `…` → **Retry deployment** (환경변수를 적용하기 위해 한 번 다시 배포)

## C. Firebase 콘솔 설정 (https://console.firebase.google.com → seohakdong-church)

1. **Authentication** → **Sign-in method** 탭 → **새 제공업체 추가** → **Google** → 사용 설정 켜기 → 프로젝트 지원 이메일 선택 → **저장**
2. **Authentication** → **Settings** 탭 → **승인된 도메인** → **도메인 추가** → `seohakdong-church.pages.dev`
3. **Firestore Database** → **규칙** 탭 → 기존 내용을 모두 지우고 `C:\project2\firestore.rules` 파일 내용을 **통째로** 붙여넣기 → **게시**

## D. 확인

1. `https://seohakdong-church.pages.dev/admin/` 접속 → **구글 계정으로 로그인** → `jangsangyun0310@gmail.com` 으로 로그인
2. "무엇을 하시겠어요?" 화면이 나오면 성공
3. **관리자 명단** 에서 다른 관리자분들의 지메일 주소를 추가하면, 그분들도 같은 방법으로 로그인해서 쓸 수 있습니다

## 평소 쓰는 법 (관리자분들께 알려드릴 내용)

- 홈페이지 맨 아래 작은 글자 **"관리자"** 를 누르고 구글 계정으로 로그인
- 한 번 로그인하면 그 다음부터는 홈페이지 오른쪽 아래에 **"✏️ 관리"** 버튼이 바로 보입니다 (관리자에게만 보임)
- 저장하면 **1~2분 뒤** 홈페이지에 반영됩니다
- 카카오톡 안에서 열면 구글 로그인이 안 될 수 있으니, 크롬/삼성인터넷/사파리로 여세요

## 주소가 바뀌었으니 같이 할 일

- 카카오톡 등으로 공유하던 예전 Netlify 주소 대신 `https://seohakdong-church.pages.dev/` 를 알리기
- `assets/img/site-qr.png` (QR 코드)는 예전 주소로 되어 있으므로 새 주소로 다시 만들기
- Netlify 사이트는 확인이 끝난 뒤 삭제해도 됩니다
